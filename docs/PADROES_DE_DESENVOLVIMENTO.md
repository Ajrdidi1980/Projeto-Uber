# Padrões de Desenvolvimento

## Código

- Uma alteração por vez.
- Não duplicar lógica.
- Reutilizar funções existentes.
- Antes de alterar, entender a arquitetura.

## Interface

- Mostrar apenas informações úteis.
- Não repetir dados que a Uber já fornece.
- Cada tela possui uma única responsabilidade.

## Fluxo

- Código
- Testes
- Documentação
- Commit
- Push
